# 👨‍💻 Arulmani S - Web Developer Portfolio

## 📋 About
A modern, responsive portfolio website showcasing my skills, projects, and services as a Web Developer. Built with HTML, CSS, and JavaScript.

## ✨ Features
- Responsive design that works on all devices
- Smooth scrolling navigation
- Interactive UI elements
- Skills section with progress bars
- Project showcase with cards
- Contact form
- Social media integration

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome Icons
- Google Fonts (Poppins)

## 🚀 Sections
- Home with introduction and stats
- About Me
- Technical & Professional Skills
- Services offered
- Featured Projects
- Contact Information

## 📱 Responsive Design
The portfolio is fully responsive and optimized for:
- Desktop (1200px+)
- Tablet (768px - 991px)
- Mobile (below 767px)

## 🎯 How to Use
1. Clone this repository
2. Open `index.html` in your browser
3. Customize the content in HTML/CSS/JS files
